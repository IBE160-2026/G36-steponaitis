  - Forsøk 2: de to sjekkene ble lagt til GitHub CI. Review ga 5 rettelser, blant annet at `SWP_EXPECT_DIALECT` stopper Postgres-jobben hvis den faller tilbake til SQLite. Commit `1610463804bb6da020206330f93dbea93d87f901`. CI-kjøring 44909080067 ble rød fordi `astral-sh/setup-uv@v10` ikke finnes.
  - Forsøk 3: pinnet til `astral-sh/setup-uv@v10.4.0`, pluss to små review-rettelser (concurrency-gruppe per hendelse, artefaktnavn per forsøk). Commit `67f0106dcb7c7ce8f6f1262b2daf4d6a910d85c4`.
- CI-kjøring 44909458803 på main er grønn i alle fire jobber:
  - Python (ruff, import-linter, pytest på SQLite)
  - `tests/app` på Postgres 17: 1 passed med `SWP_EXPECT_DIALECT=postgresql`
  - Frontend (ESLint, typecheck, Vitest)
  - End-to-end (Playwright, Chromium): 3 passed
- Rødsjekk: kastebranchen `ci-red-check` med `import sqlalchemy` i `backend/swp/domain/__init__.py` ga kjøring 44909613482. Python-jobben ble rød (import-linter). Branchen er slettet både på origin og lokalt.
- Lokal verifisering: `npm ci`, `lint:py`, `lint:imports` (4 kept), `lint`, `typecheck`, `npm test` (36 pytest + 5 Vitest) og `CI=true npm run e2e -- --project=chromium` (3 passed) var alle grønne.
