# UX-alternativer

## 2026-11-14 kl. 17:58 — Justas

### Oppgave
Brukeren var ikke fornøyd med flere av Bin Wall-mockupene (liker forsiden og login). Ønsket tre alternativer hver for warehouse layout, screen map, interface, features menu, components sheet og components sheet 2, laget av subagenter, flettet inn og presentert for valg.

### Plan
- Seks subagenter, én per flate, hver i sitt eget git-worktree; tre alternativer (A/B/C) som SVG med generator og NOTES.md i `.docs/planning-artifacts/ux-designs/ux-Project-2026-11-11/.working/alternatives-2026-11-14/<flate>/`.
- Felles brief: faste Bin Wall-beslutninger fra `.memlog.md`, visuelt språk fra `mockups/landing.svg` og `mockups/login.svg` (gjenbruk `defs.svgfrag`), kun syntetiske data, ikke endre `mockups/` eller spinene.
- Flette grenene inn i main, rydde worktrees, bygge et galleri for å sammenligne og velge.

- Galleri `.working/alternatives-2026-11-14/index.html` (commit `41f82dc`), publisert som privat artefakt: https://claude.ai/artifact/Rn1HNMNhkiZpqtiSki5cmg — med «Pick this one» per flate og «Copy picks».
