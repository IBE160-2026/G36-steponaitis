# 03 · Visible Record Index

**Thesis.** Before software, stock was planned on visible-record cabinets. This concept refuses the heat-map grid with a colour legend. Each location is a strip and each stored part a rider, so a misfit is a rider in the wrong column.

**Own world.** Enamelled steel shell (`#2F3B44`, `#3F4D57`, `#4E5D68`, tray `#36434D`). Ledger-green card stock (`#E5EEE1`, `#D9E5D4`) with black ink `#172026`. Riders: red `#B8322A`, blue `#2C5AA0`, yellow `#E3B21C`, black `#15191C`, plain steel `#9AA6AE`. Public Sans for the UI, Courier Prime only for card data.

**Signature move: signal riders.** Position on the strip shows the movement class, from Fast on the left to Dead on the right. Shape and colour show the state:

- Steel bar: stored part
- Red arrow: recommendation pending
- Black, punched: keep in place
- Yellow, cut corner: outdated
- Blue swallowtail on the label end: best location

Empty locations are dashed strips.

**Warehouse layout.** Nine drawers side by side, with occupancy on each label holder. Each drawer has sections as rows, levels inside each section and positions across. Pull one out to read full-size strips; hover pops up the record card. A recommendation is drawn as a lifted card moving between drawers.

**Navigation.** Standard tabs in flow order, each with a step number. The plan menu is a cabinet front with locked stage-2 drawers.

**Risk.** Overview strips are tiny, so shape cues work only in the pulled-out drawer.

**Trust.** Every rider sits where its numbers put it.
