# 04 — Construction Drawing Set

**Thesis.** A re-slotting plan is a set of construction drawings: what exists, what is proposed, and a record of every revision. It rejects the dashboard default of cards, KPI tiles and heatmaps.

**Own world.** Whiteprint sheet `#F7F8FC` on desk `#E7E9F2`, blue-violet ink `#26296B` / `#474B8C` / `#5F64A0`, grid `#CDD0E6`, and one redline `#C23B1E` reserved for changes. Archivo Narrow caps for labels, Archivo for body text, tabular figures. Sheet borders, grid bubbles, section hatching, title block, section-cut markers.

**Signature move: revision clouds and delta triangles.** Each location a move touches gets a cloud, and its delta carries the ROUND number. The title block's revision table lists the rounds (△1 Round 1 — 12 moves — 2026-11-11). Dashed = existing or proposed, solid = applied.

**Warehouse layout (A-800).** A plan with grid bubbles A–I and sections 01–19, every location a cell. F is crosshatched, M hatched, S sparsely hatched, D stippled, and empty cells are blank. Best locations get a heavy outline and a BEST tag. A section cut links to an elevation of aisle A with letter tags. Plus occupancy schedule, key, general notes.

**Navigation.** A sheet-index sidebar (A-000 to A-700 in flow order, stage 2 as future phase) and a Ctrl+K drawing-index palette where digits jump to sheets.

**Honest risk.** At small sizes the hatching turns to grey tone, so single locations need zoom.

**Why a planner would trust it:** every change is clouded, numbered by round and explained, like a signed drawing.
