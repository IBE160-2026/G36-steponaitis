- (decision) Recommendation status stored: open | applied | outdated(+cause). After every command domain.recommendations.revalidate turns invalid open recs to outdated (sticky until next run). FR-34 removal by moving back is a move, not an undo. An applied rec stays applied while its step exists, even if FR-34 later combines it into a Manual move. A rec whose part is kept in place is shown under Kept in place and cannot be applied; removing the mark returns it to open if still valid (not sticky).
