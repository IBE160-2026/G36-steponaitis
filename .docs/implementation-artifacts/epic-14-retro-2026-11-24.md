### Duplication map

- **D1 — `_ref(code, location) -> LocationRef` is duplicated verbatim** in `backend/swp/domain/labels.py:27-36` and `backend/swp/domain/layout.py:123-132`. The spec told the story to copy rather than import, because domain slices may not import each other (`backend/.importlinter` `domain-slices`). The project convention is that shared code moves to the kernel (AGENTS.md "shared code in common folders"; epics.md "Epic Design"). A builder of an unmarked `LocationRef` from `LocationData` belongs next to `LocationRef` in `domain/planning.py`. **Disposition:** defer (low; two copies, identical).
- **D2 — `IMMUTABLE` is imported from another router** (`backend/swp/api/routers/labels.py:9` imports from `routers/layout.py:15`). The build review rejected moving it (spec, triage log). It is one constant, but it makes `layout` a dependency of `labels` at the API layer. **Disposition:** defer, bundle with D1.
- **D3 — The print paper pattern is copied** from `modules/move-list/move-list-page.tsx:151` into `modules/labels/labels-page.tsx:101-102` (same `max-w-[210mm] bg-print-paper … print:p-0 print:shadow-none` classes). The spec asked for a copy, not an import, and two copies is within the convention's "a second module needs it" threshold for moving to `components/common`. **Disposition:** accept for now; move to a common `PrintPaper` if a third print view appears.
