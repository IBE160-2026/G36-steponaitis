# Epic 1 Context: Start a plan from the warehouse's exports

<!-- Generated from planning artifacts. Regenerate with compile-epic-context if planning docs change. -->

## Goal

The planner uploads the three warehouse exports (Locations, Inventory, Transactions) and gets either a stored plan or an exact per-file list of what is wrong, then lands on a plan overview showing the data-as-of date and the settings the plan was computed with. The epic also lays the foundation every later slice reuses: a local walking skeleton (backend + frontend started by one command), CI on every push, the shared kernel (domain, store, API errors, guards), the design tokens and app shell (toolbar, plan plate, flow bar), and the milestone 1 start redirect. Deployment is deferred: everything is built and verified locally (no Vercel/Supabase).

## Stories

- Story 1.2: CI on every push

## Requirements & Constraints

- **New Plan:** name + three files; `.xlsx`, or UTF-8 `.csv` with header and `,`/`;` delimiter. No column-mapping screen. A plan is created only if all three files pass; nothing from a rejected import is saved. `data/sample/` must import cleanly.
- **Required columns** (matched trimmed, case-insensitive): Locations: Location, Walk Path, Aisle, Level · Inventory: Part, Part Description, Quantity, Location · Transactions: Transaction Type, Part, Location, Transaction Code, Date. Missing or duplicated required column → error naming file and column.
- **Value checks** (error names file, row, column, value): blank required cell; Quantity non-numeric or negative; Walk Path non-numeric; unreadable Date; thousands separators; non-integral identifier; duplicate location code in Locations; empty file; unreadable file / wrong extension (names the file). Report every error in every file, max 20 per file plus a "more" count.
- **Location references:** every inventory row and shelf line (Move to Repair, Return to Stock, Receipt) must reference a known location; Issue Part at a virtual location (e.g. `FLSKRS`) is accepted; other transaction types accepted and ignored. Transaction types match ignoring case.
- **Normalization:** part numbers and location codes kept as exact text (`0100`, `1008614-00`, `A-01-01-01-A1`); integral numeric identifiers become integer text without `.0`; text trimmed incl. NBSP; duplicate part+location inventory rows merged (quantities summed), zero-stock rows kept; more than one Warehouse value within or across files → reject naming the file.
- **Dates:** data-as-of = newest transaction date over all Transactions rows (answer-key gives 2026-09-30); upload date recorded. Both shown on the plan.
- **Who:** `created_by`/`last_edited_by` = fixed `planner` in M1 (auth off); `last_edited_at` = `created_at` on creation. GETs never write or touch last-edited.
- **Settings:** period length, class limits and pick-group minimum live in `backend/settings/analysis.toml`; each plan stores a snapshot (incl. period start/end) and shows it read-only. Class counts show zero until Epic 2.
- **Limits:** `MAX_UPLOAD_BYTES` 4,000,000 (browser pre-checks too), `MAX_ROWS_PER_FILE` 25,000 → `limit_reached` 413 with a message like "transactions.xlsx has more than 25,000 rows. One file can hold at most 25,000."
- **Non-functional:** runs on a laptop with zero env vars, no paid accounts, no runtime network calls, no AI/LLM at runtime; plans persist across restarts; import + analysis of demo data < 10 s; English UI; only synthetic data in repo (never `data/private/` or company files; never edit `data/sample/` or `data/answer-key/`); WCAG 2.2 AA floor; desktop Chrome/Edge/Firefox.
- **Tests:** each test names its FR/NFR (e.g. `test_fr3_*`, `test_fr4_*`, `test_nfr6_cross_site_post_rejected`). Domain tests in `backend/tests/domain` use small synthetic fixtures; `tests/app` runs on SQLite and on Postgres 17 in CI. Every user-visible story adds/extends a Playwright test in `frontend/e2e/` naming its journey (e.g. `uj1 imports the sample files`) and asserting visible results; `npx playwright test --project=chromium` must pass.

## Technical Decisions

- **Pinned stack (exact versions):** Python 3.12 (`.python-version`, `requires-python >=3.12,<3.13`), uv 0.13.8, FastAPI 0.163.1, python-multipart 0.0.34, Uvicorn 0.54.0, Pydantic 2.14.3 / pydantic-settings 2.16.3, SQLAlchemy 2.1.8, Alembic 1.20.1, psycopg 3.3.9 (binary, Postgres only), openpyxl 3.1.5 / defusedxml 0.7.1, pytest 9.2.0 / httpx2 2.16.2, ruff 0.17.5 / import-linter 2.16; Node 24 LTS (`engines` 24.x), Next.js 16.4.6 (App Router), React 19.3.1, TypeScript 5.9.3, Tailwind 4.3.5, shadcn CLI 4.23.0 (`init -b radix`), TanStack Query 5.107.1, zod 4.6.7 (form input only), sonner 2.0.8, lucide-react 1.73.0, @fontsource/figtree + @fontsource/barlow-semi-condensed 5.3.0, openapi-typescript 7.13.0, Vitest 5.1.0, Playwright 1.65.1, concurrently 10.0.7; Postgres 17 in CI.
- **Skeleton:** `backend/` (uv project, package `swp` with `domain/ app/ store/ api/`, `config.py` via pydantic-settings, `cli.py` with `swp db upgrade` / `swp openapi`, `main.py`) and `frontend/`; root `package.json` `npm run dev` runs uvicorn :8000 + `next dev` :3000 via concurrently with `NEXT_TELEMETRY_DISABLED=1`. `GET /api/health` does `SELECT 1` on SQLite `backend/var/swp.db` (created if missing). `.gitignore` covers `backend/var/` (+ `-wal/-shm/-journal`), `data/private/*`, `.env*` except examples, test/Playwright outputs.
- **Layering (AD-1/AD-2):** `swp.domain` is pure — stdlib + pydantic only; `uuid4`, `datetime.now`, `random` banned via ruff `banned-api`; time/user enter as `CommandContext(now, user)`. Only `swp.store` imports SQLAlchemy. Layer order domain → store → app → api → frontend enforced by import-linter. All routers under `/api`; browser calls relative `/api/*` only (local Next.js rewrite to `127.0.0.1:8000/api/:path*`); client fetching via TanStack Query only — no server components, route handlers or server actions calling the backend. No CORS.
- **CI (`ci.yml`, every push):** ruff, import-linter, ESLint, pytest on SQLite, `tests/app` on Postgres 17 service (incl. health `SELECT 1`), frontend typecheck, Vitest, and an `e2e` job running Playwright Chromium (`--pass-with-no-tests` until the first test; upload reports on failure). OpenAPI schema diff is added by the story that first generates `schema.ts` (1.7).
- **Import (AD-8):** readers in `swp/app/imports/readers.py` produce `RawSheet` of typed cells (`str|int|Decimal|datetime|date|None`). `.xlsx`: openpyxl + defusedxml, read-only, values-only, first sheet, reject >50 MB uncompressed, stop at `MAX_ROWS_PER_FILE+1`, 100 columns, 1,000 chars/cell, floats → `Decimal(repr(f))`. `.csv`: UTF-8, BOM stripped, delimiter = more frequent of `,`/`;` in header. Validation lives in `domain.import_` (module named `import_`): header = first non-blank row, blank rows skipped, spreadsheet row numbers (header = row 1), dates as date cells, `YYYY-MM-DD` or `DD.MM.YYYY` (+optional discarded time). Error details per file: `{file_role, file_name, status: passed|failed|not_checked, errors: [{row, column, message}] (≤20), more_count}`. Save is all-or-nothing in one transaction (import + plan + analysis).
- **Data model (AD-4, AD-9):** first migration creates only `imports` (`id`, `uploaded_at`, `data_as_of`, `data` JSON — normalized locations keyed by code, merged inventory, parts with first non-blank description, reduced transactions, `schema_version`; file bytes never stored; frozen) and `plans` (`id`, `name`, `import_id` FK `ON DELETE RESTRICT`, `created_by/at`, `last_edited_by/at`, `version`, `analysis` JSON, `state` JSON). Portable types only (`Uuid`, `JSON`, `UtcDateTime`); JSON written whole via `model_dump(mode="json")`; Alembic `render_as_batch=True`, expand-only. `PlanState.new()` declares every field with defaults (marks, keep marks, runs, steps, `next_move_number`, `recent_commands`) + `schema_version`; upcasters in `domain/state_migrations.py` with a `state_v1` fixture. `swp.app.bootstrap(upgrade, seed)` is the only migrate/seed path (lifespan only when `APP_ENV=local`). `app.plans.create(import, settings)` is the only plan-creation path and always recomputes analysis from `analysis.toml`.
- **API surface this epic:** `GET /api/health`; `POST /api/plans` (multipart, not idempotent); `GET /api/plans` (list, used for the `/` redirect); `GET /api/plans/{id}` (summary: name, data-as-of, upload instant, current round 0, `version`, step check states and counts); `GET /api/session` → `{user: null, feature_auth: false, feature_demo: false, max_upload_bytes}`.
- **Errors (AD-11):** envelope `{"error": {code, message, details}}` with closed codes (`import_invalid` 422, `validation_failed` 422, `plan_not_found` 404, `limit_reached` 413, `forbidden_origin` 403, `internal` 500, …). Domain raises `DomainError(code, message, details)`; only `swp/api` maps to HTTP. Backend messages are final English with no dates/times; frontend branches only on `code`; non-envelope → `internal`. FastAPI validation errors → `validation_failed`.
- **Same-origin guard (AD-19):** reject POST/PUT/PATCH/DELETE with `forbidden_origin` unless `Sec-Fetch-Site: same-origin` or (header absent) `Origin` matches host. JSON bodies only except multipart `POST /api/plans`.
- **Generated types (AD-13):** `swp openapi` + `openapi-typescript` → `frontend/lib/api/schema.ts`; snake_case JSON; CI fails on diff.
- **Client (AD-12, AD-20):** one shared TanStack Query error hook for GETs (`plan_not_found` → toast "This plan was deleted." and open New Plan). URLs `/plans/{id}/{step}` built only by `frontend/lib/view-state`. `/` in M1 redirects to most recently edited plan or `/plans/new`.
- **Conventions:** glossary terms verbatim; UUIDs for plan/import; quantities and Walk Path as `domain.values.Dec` normalized decimal strings; instants stored UTC, sent ISO 8601 with `Z`, formatted only in the frontend in the viewer's zone; `data_as_of`/period as `YYYY-MM-DD`; stdlib logging, one line per request (method, path, status, ms), full traceback for `internal`; fonts self-hosted via @fontsource (never `next/font/google` or CDN).
- **Vertical slices with a shared kernel:** each epic is a slice owning its domain module (`swp/domain/<slice>.py`), service (`swp/app/<slice>/`), router (`swp/api/routers/<slice>.py`), frontend module (`frontend/modules/<slice>/`) and tests. Shared code goes in common folders, built once: domain kernel (`values.py`, `ordering.py`, `planning.py`, `state.py`, `state_migrations.py`, `commands.py`, `errors.py`, `views/common.py`), `app/` shared (`plans.py`, `commands.py`, `bootstrap.py`, `limits.py`), `store/` (sole persistence), `api/` shared (`errors.py`, `deps.py`, `origin_guard.py`, `main.py`), `frontend/components/ui/` (shadcn), `frontend/components/common/` (components used by ≥2 slices), `frontend/lib/` (`api/`, `commands/`, `copy/`, `view-state/`, `format/`), thin routes in `frontend/app/`. Rules enforced in CI: a domain slice imports only the kernel, never another slice (import-linter independence contract, with listed exceptions for later epics); a frontend module imports only `components/*` and `lib/*`, never another module (ESLint `no-restricted-imports`) — anything a second module needs moves to common in that same story; all plan changes go through the single command endpoint (arrives in Epic 3). Epic 1 slices: `domain/import_`, `app/imports`, `app/plans`, `modules/new-plan`, `modules/overview`, `modules/settings`.

## UX & Interaction Patterns

- **Design foundation:** DESIGN.md tokens as the Tailwind 4 theme (colours, type ramp — Barlow Semi Condensed for codes/counts, Figtree for reading — radii, spacing, fixed sizes); tabular numbers everywhere; nothing below 11px; light theme only. Fixed focus ring: on paper 2px white gap + 2px ink ring; on graphite 2px `#141719` inner + 2px white outer; never recoloured.
- **Shared components (`components/common/`):** ClassGlyph (▲ ◆ ▼ slashed ring as SVG paths, no emoji/Unicode), outline icon set, Button (primary/secondary/tertiary/link/destructive; disabled keeps label, stays focusable with `aria-disabled` and reason via `aria-describedby`; "…" when a dialog follows), Input/InputError (`aria-invalid`), Toast (sonner, bottom-left, one at a time, ≥10 s, pauses on hover/focus, `aria-live="polite"`), GlobalNotice strip, ConfirmDialog (Cancel first and focused). `lib/format`: `YYYY-MM-DD`, `HH:MM`, thousands separators.
- **App shell:** 64px graphite toolbar (sticky except below ~500px height) with product mark (fixed brand yellow), name "Smart Warehouse Planner", plan plate, flow bar. Plan plate: name + "Data as of YYYY-MM-DD · round 0", upload date in tooltip, menu with only New Plan in M1. Flow bar: eight steps (Overview, Parts, Locations, Pick groups, Best locations, Recommendations, Before/after, Move list) as navigation, current step `aria-current="step"` (white pill), steps 1–4 checked once a plan exists with visually hidden "done" text; collapses below 1024px to "Step N of 8 · <name> ▾".
- **New Plan screen:** required name ("Give the plan a name."; names need not be unique), three file tiles, New Plan as the one primary. Over-size pre-check: "These files are 5.2 MB together. One New Plan can upload at most 4 MB." with submit disabled. Two-stage progress: "Uploading 3 files · 1.2 of 2.8 MB" with Cancel, then "Checking files and computing classes and pick groups…" without Cancel; submit disabled in flight, never retried. Success → overview with toast "<name> created. Data as of <date>."
- **Import error panel:** `role="alert"`, pale red with red border and warning triangle, "Import stopped: nothing was saved.", lines "<file> · row N · column X: “value” …" up to 20 then "and N more in this file"; failing tile outlined red with triangle, passed tiles show a check and stay chosen so only the failing file is re-chosen.
- **Overview & Settings:** data-as-of, upload date (local date), period, settings, counts per class, best/empty-best and kept counts; loading shows "Opening <name>…" as text, no spinner. Settings read-only with "Changed in the config file, not in the app."
- **Copy & accessibility:** sentence case, glossary terms verbatim, no exclamation marks/emoji/praise; every plan surface shows data-as-of. No information by colour alone; keyboard-usable forms; reduced motion respected (no slide, animations ≤200 ms); page never scrolls sideways down to 320px.
