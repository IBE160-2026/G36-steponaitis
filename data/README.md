# Data

- `sample/` — synthetic demo Excel files used during the course. These are committed to the repo.
- `private/` — original company files. This folder is ignored by git and must never be committed.

## Demo data

The files in `sample/` are generated by `generate_demo_data.py` (fixed seed, so the output is the same every run). Run from the project root:

    uv run --with pandas --with openpyxl python data/generate_demo_data.py

| File | Rows | Columns |
| --- | --- | --- |
| `Locations.xlsx` | 2,000 | Location, Aisle, Section, Level, Position, Warehouse |
| `Inventory.xlsx` | 2,000 | Part, Part Description, Quantity, Unit, Location, Warehouse |
| `transactions.xlsx` | 20,000 | Part, Part Description, Location, Transferred Quantity, Initial Quantity, Transaction Code, Date |

- 9 aisles (A–I), location code `<aisle>-<section>-<level>-<position>`, e.g. `A-01-02-03`.
- Every location holds one car part; about 8% have zero stock.
- Negative Transferred Quantity is a pick, positive is a receipt. Initial Quantity + Transferred Quantity is the stock after the line, and each part's last line ends at its quantity in `Inventory.xlsx`.
- Several lines can share a Transaction Code (up to 4 parts picked together). Some part pairs, such as an oil filter and engine oil for the same car, are picked together often.
- Dates are random weekdays from 2025-10-01 to 2026-09-30, 07:00–15:30.
- Some parts are fast movers, most move rarely, and about a quarter never move (dead stock).
