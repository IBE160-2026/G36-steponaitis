# Data

- `sample/` — synthetic demo Excel files used during the course. These are committed to the repo.
- `private/` — ignored by git. Real company data must never be committed, and the course project does not use it.

## Demo data

The files in `sample/` are generated by `generate_demo_data.py` (fixed seed, so the output is the same every run). Run from the project root:

    uv run --with pandas --with openpyxl python data/generate_demo_data.py

| File | Rows | Columns |
| --- | --- | --- |
| `Locations.xlsx` | 2,000 | Location, Aisle, Section, Level, Position, Warehouse |
| `Inventory.xlsx` | 1,625 (1,545 parts) | Part, Part Description, Quantity, Unit, Location, Warehouse |
| `transactions.xlsx` | 20,000 | Transaction Type, Part, Part Description, Location, Transferred Quantity, Initial Quantity, Transaction Code, Date |

- One warehouse, `NO`, with 9 aisles (A–I). Location code `<aisle>-<section>-<level>-<position>`, e.g. `A-01-02-03`.
- Aisles are 65–87% occupied. 375 locations hold no part (they are not in `Inventory.xlsx`) and 41 hold only a zero-stock part, so 416 count as empty.
- 80 parts are stored in two locations.
- Transaction types follow the real process:
  - **Move to Repair**: pick from the shelf to the virtual location `FLSKRS`, one part per Transaction Code.
  - **Issue Part**: the part is used, at `FLSKRS`. All parts on one job share its Transaction Code; use these lines for pick-together analysis.
  - **Return to Stock**: an unused part goes back to the shelf it came from.
  - **Receipt**: goods received to a shelf, Transaction Code `0` (not groupable).
- On shelf lines, Initial Quantity + Transferred Quantity is the stock after the line, and each part's last line per location ends at its quantity in `Inventory.xlsx`. On Issue Part lines, Initial Quantity is what was waiting at `FLSKRS` for that part.
- Some part pairs, such as brake pads and brake discs for the same car, are used together often.
- Dates are random weekdays from 2025-10-01 to 2026-09-30, 07:00–15:30. A job is picked in the morning and issued or returned later the same day.
- Some parts are fast movers, most move rarely, and 636 parts never move (dead stock).
